# Comet Pizza — Menu

Comet Pizza is a fictional pizza shop offering takeout and delivery. All prices are in Japanese yen and include tax.
Each item has an ID (for example P01) so staff can confirm orders accurately.

## Pizzas

## Set Menus

Set menus are cheaper than ordering each item separately. When a customer orders items that match a set, suggest the set.

| ID | Set | Japanese name | Contents | Price |
|---|---|---|---|---|
| S01 | Solo Set | ソロセット | 1 S pizza (P01–P10) + French Fries + 1 drink (B01–B05) | Pizza price + ¥400 |
| S02 | Pair Set | ペアセット | 1 M pizza + Chicken Nuggets (5 pcs) + 2 drinks (B01–B05) | Pizza price + ¥800 |
| S03 | Party Set | パーティーセット | 2 L pizzas + Chicken Nuggets (10 pcs) + French Fries + Cola (1.5 L) | Pizza prices + ¥1,300 |
| S04 | Nugget Snack Set | ナゲットスナックセット | Chicken Nuggets (10 pcs) + French Fries + 1 drink (B01–B05) | ¥1,300 |

Set notes:
- Extra toppings and crust upgrades on set pizzas are charged at the normal price.
- In a set, a drink can be changed to Oolong Tea at no charge; Cola (1.5 L) is only in the Party Set.

## Ordering Information

- Takeout: ready in about 20 minutes.
- Delivery: about 40 minutes; minimum order ¥1,500; delivery fee ¥300 (free for orders of ¥3,000 or more).
- Opening hours: 11:00 – 23:00 every day (last order 22:30).
- Payment: cash, credit card, or QR code payment.
- Allergens: pizzas contain wheat and milk. P05 and T08 contain shrimp. P04 and P10 contain egg (mayonnaise). Please tell staff about allergies.
